六、数据流图
================================================================================

1. 视频分析数据流
--------------------------------------------------------------------------------

  [视频源]        [帧采样]         [图像分析]        [结果整合]      [存储展示]
      |               |                 |                 |               |
      v               v                 v                 v               v

+----------+    +----------+      +----------+      +----------+    +----------+
|          |    |          |      |          |      |          |    |          |
| WebRTC   |--->| 5秒窗口  |----->| SurgR1   |----->| GLM      |--->| MySQL    |
| 视频流   |    | 1帧/秒   |      | 3问题    |      | 总结     |    | 存储     |
|          |    | 5帧/窗口 |      |          |      |          |    |          |
+----------+    +----------+      +----+-----+      +----------+    +-----+----+
                                       |                                  |
                                       v                                  v
                                  +----------+                      +----------+
                                  | SAM3     |                      | 前端     |
                                  | 分割     |                      | 展示     |
                                  +----------+                      +----------+


2. 语音交互数据流
--------------------------------------------------------------------------------

  [麦克风]       [语音识别]        [对话处理]        [响应生成]      [语音输出]
      |               |                 |                 |               |
      v               v                 v                 v               v

+----------+    +----------+      +----------+      +----------+    +----------+
|          |    |          |      |          |      |          |    |          |
| 音频     |--->| FunASR   |----->| 对话     |----->| GLM      |--->| CosyVoice|
| 采集     |    | 识别     |      | 服务     |      | 回答     |    | 合成     |
| 16kHz    |    |          |      |          |      |          |    |          |
+----------+    +----+-----+      +----+-----+      +----------+    +-----+----+
                     |                 |                                  |
                     v                 v                                  v
                +----------+      +----------+                      +----------+
                | 唤醒词   |      | MySQL    |                      | 音频     |
                | 检测     |      | 上下文   |                      | 播放     |
                +----------+      +----------+                      +----------+
