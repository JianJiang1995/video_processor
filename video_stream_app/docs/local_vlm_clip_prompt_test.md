# 本地 VLM 手术夹识别 Prompt 测试

## Prompt 文件

- `prompts/surgical_clip_detection_prompt_zh.txt`

该 prompt 面向完整腹腔镜帧输入，不依赖人工裁剪。核心流程是先在完整视野中定位候选夹子，再根据颜色、材质、粗细、形状和空间关系判断 Hem-o-lok 或钛夹。

## 视觉判别要点

Hem-o-lok / 聚合物锁扣夹：
- 常见蓝紫色、深蓝色、紫色，也可能是白色、乳白色、象牙白或绿色。
- 材质偏塑料，金属反光弱。
- 形态更粗、更宽、边缘圆钝，常见两条近似平行夹臂、倒 V 形、U 形、短条状或门形结构。
- 白色或乳白色粗夹臂即使有局部高光，也按 Hem-o-lok 处理，不按钛夹处理。
- 常夹在胆囊管或胆囊动脉上，放置后相对组织稳定。

钛夹 / 金属夹：
- 银灰色、金属银色、灰白金属色或暗灰色，可有锐利白色高光。
- 通常比 Hem-o-lok 更细小、更薄，呈短线、V 形、U 形或微弯金属片。
- 可见多枚平行短金属夹片时，应优先判定为钛夹。
- 只有看到夹子本体时才判定钛夹；单独看到钛夹钳或施夹器不算。

负例：
- 白色施夹器头、白色电凝钩、强反光、烟雾、纱布、组织高光不算 Hem-o-lok。
- 剪刀刃、抓钳齿、钳口、吸引器口、电凝钩尖端不算钛夹。

## 匿名参考帧回归

模型：`GLM-4.6V-Flash-AWQ-4bit`

输入：单张完整帧，不裁剪，不传文件名或期望类别，`temperature=0`，`enable_thinking=false`，JSON 输出。

| 样本类型 | 输出 | 结论 |
|---|---:|---:|
| 蓝紫色 Hem-o-lok | hemolok | 通过 |
| 明确负例 | none | 通过 |
| 小目标/遮挡钛夹 | none 或 uncertain | 当前 GLM-V 不稳定 |

说明：早期参考帧测试曾把文件名传入 prompt，文件名包含 `hemolok/titanium`，该结果不再作为有效结论。有效结论以匿名参考帧和整段自动扫描为准。

## 整段视频自动扫描测试

为避免硬编码某一帧或某个时间点，额外做了整段视频扫描：
- 固定每 `10s` 取一个窗口。
- 每个窗口取 `+0s/+2s/+4s/+6s` 四张完整帧。
- 不裁剪，不传入样本名、期望类别或已知事件时间。
- 只把图像和通用 prompt 发给本地 VLM。

## 当前结论

可以实现：
- 完整帧输入下识别蓝紫色 Hem-o-lok。
- 完整帧输入下稳定识别 VID001 中的白色 Hem-o-lok，并解决 Hem-o-lok/titanium 跳变。
- 作为实时分析的额外 VLM 模块输出夹闭事件和候选框。

暂不应直接作为唯一最终结论：
- 当前 GLM-V 对很小或被器械遮挡的钛夹召回不足。
- bbox 可用于辅助展示和人工复核，但不能当作像素级检测框。
- `uncertain` 只能作为候选提示，不能作为已确认夹闭事件。

推荐接入策略：
- 只把 `confidence >= 0.8` 且 `clip_type` 为 `hemolok` 或 `titanium` 的结果写入右侧分析。
- 连续相邻窗口同类命中时合并成一个夹闭事件节点。
- `uncertain` 只进入内部候选池，不直接展示为确定结论。
- 与 Triplet/phase 规则做后处理：夹闭切断阶段附近优先触发本地 VLM；剪断胆囊管或胆囊动脉前必须先有同目标夹闭证据。
