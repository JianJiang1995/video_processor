## 修改范围

1. `_stable_expert_phase` 在没有前序窗口时，如果准备与肝胆三角解剖恰好并列最高，优先选择准备。明确的其他阶段仍保留，避免把术中截取的视频一律当成术前准备。该选择同时作用于快速初稿和本地 VLM 后更新。
2. 增加输入布局配置 `config.json -> analysis_overlay_exclusions`。坐标为裁剪后的画面比例 `(x1, y1, x2, y2)`，不依赖视频名、帧编号或时间戳。
3. 当前 `quad_right` 配置排除右上角 `(0.9375, 0, 1, 0.095)` 和右下角 `(0.895, 0.915, 1, 1)`。其他布局默认不排除，可按设备叠加层位置独立配置；换设备或改变布局时需重新核对位置。
4. 模型输入缩小后才遮盖两处区域。YOLO、Phase、Triplet、夹子专家、本地 VLM、SurgR1 异步复核及历史窗口重新分析使用相同规则。原始帧、播放画面、回放、时间戳不修改。
5. 修正 YOLO 预热注册 `persist=False` 导致后续跟踪 ID 每帧重置的问题。预热改为持久跟踪并清空预热状态。
6. 抓钳、冲洗器等全部器械统一过滤仅单帧出现的 YOLO 存在性描述，不再遗漏类别。该过滤不把器械存在自动推断成具体动作。

## 验证

用第一段录制保存的原始帧、本机同一 YOLO 和 Phase 权重，在独立 CPU 进程复测，不写回原分析数据库，不录屏。

## Electron 实时复测中发现的后更新问题

用户要求重跑第一段视频后，在 Electron 中使用同一原文件、`quad_right` 布局及真实本地模型按播放速度重新分析，没有录屏。

首次会话 `52ae6753` 的第 5 窗口（20-25 秒）初稿没有器械，但后更新写入了“抓钳牵拉脂肪组织”。抽查该窗口的原始采样图片，没有看到相应抓钳。保存的 YOLO 器械列表为空；SurgR1 原始候选却有抓钳，主 VLM 又产生了器械动作。独立复核虽然返回空器械列表，但只用了夹子检测触发的两帧，不满足已有的三帧空器械复核条件，未能排除错误。这次尝试已停止，不作为完整通过的复测。

补充修复：

1. YOLO 明确返回空器械列表时，不把 SurgR1 的器械动作候选写进主 VLM 提示词，避免文字候选引导误判。SurgR1 仍运行，原始响应仍保存；VLM 仍读取图像，可以独立发现检测器漏检的真实器械。
2. YOLO 空列表与主 VLM 的具名器械观察冲突时，触发独立器械复核，均匀采样窗口内至少三张图，而不是只检查一两张夹子检测命中图。
3. 只有复核成功、高置信度、明确空器械列表且覆盖至少三张非夹子触发采样图时，才排除相冲突的器械动作。文字和结构化观察一起处理，原候选保存到 `rejected_observations`，防止后续汇总再次引用。
4. 缺失 YOLO 数据不等同空列表；复核失败或采样不足不构成“无器械”的证据。以上复核位于异步后更新链路，不阻塞快速初稿。
