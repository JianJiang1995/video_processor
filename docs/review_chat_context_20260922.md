# 片段回看智能问答：全视频上下文

更新时间：2026-09-22。

## 用户问题与根因

会话 `6d8689f7`，回看片段 `0:05-0:10`，用户实际提出：

1. `what you can see in this period?`
2. `what's the time does the instrument firstly show`

原实现将数据库窗口过滤成只与回看时间重叠的记录，系统提示词还明确限制回答当前片段。
因此第二问虽然在问整个视频的首次器械记录，也只得到“当前片段没有记录，无法判断”。

另发现 `GET /api/voice/chat/{session_id}/history` 调用了不存在的
`MySQLService.get_conversation_history`，导致接口返回空列表和错误。
用户两条原问题及回答实际已保存在 MySQL，并未丢失。

## 新机制

- 当前片段是定位信息，不再限制问答可访问的时间范围。
- 每次请求按会话 ID 从数据库重新读取全部有效窗口摘要和阶段，按视频时间排序。
  手动复核或异步更新后的结果会用于下一次问答，不依赖前端缓存摘要。
- 单独提供当前片段的重叠记录。“这里、这个片段、this period”仍指当前回看区间。
- 首次出现、之前或之后的操作、全视频比较等问题可使用选中区间外的记录。
- 当前视频尚未分析到的部分不可用；有记录的起止边界不代表中间没有缺口。
- 原始窗口保留独立，不因问答而合并、覆盖、重新分析或删除。
- 最近用户问题从服务器历史读取，最多六条、2400 字符，用于理解追问。
  **不把旧模型回答再作为上下文输入**：实测发现即使明确声明旧回答可能错误，本地
  Qwen3-VL 仍会复制历史中的“只能看当前片段”答案。所有旧回答仍保存在数据库中。
- 问答历史读写接口使用现有 `get_chat_history` / `clear_chat` 方法；历史按时间、ID
  稳定排序。本轮没有调用真实会话的清空接口。
- 前端上下文标识改为“基于全视频已分析记录，定位当前片段”，同时更新英文标识。

相关代码：

- `backend/services/conversation_service.py`：数据读取、当前片段定位、全视频提示词。
- `backend/services/chat_context.py`：超出模型上下文后的记录级检索。
- `backend/routers/voice.py`：问答历史接口。
- `backend/services/mysql_service.py`：问答历史排序。
- `frontend/src/i18n.js`：上下文标识。

## 长视频与边界

正常情况下完整传入所有有效窗口。本轮实际传入 130 个窗口，不仅是当前窗口或最后十个窗口。
没有新增视觉模型调用，使用原来的本地 Qwen3-VL-8B-Instruct 文本问答接口。

极长视频超出模型长度时，沿用客户端的完整记录摘选重试。摘选优先保留当前片段与覆盖说明，
支持器械、出血、起雾、剪刀、夹子等中英文检索词；问“最早”时优先较早的同等相关记录。
不会切断一个摘要后把残句当作完整证据。摘选标识要求模型说明证据不完整，不能保证整段数量、
事件不存在或真实首次出现时间。不能把该机制说成无限上下文或全视频逐帧检索。

这里只读取已有分析记录，没有为每次问答重新查看原始画面。“最早记录”不等于“最早实际出现”，
也不能把多个窗口中的重复施夹描述直接累加为夹子数量。

## 实际验证

使用原会话、真实 Electron 界面、真实本地模型，不伪造响应，不修改视频或写死答案。
重启后端后重新加载原会话进行回看，没有重新执行整段视觉分析。

- 第一问仍正确定位 `0:05-0:10` 的已有记录，17.22 秒返回。
- 第二问在同一个 `0:05-0:10` 回看窗口里，查到 `0:40-0:45` 的器械接触记录，14.45 秒返回。
- 点击第二问中的时间戳，打开窗口 9 的 `0:40-0:45` 回放，画面持续运动，仍只有一个回看弹窗。
- 原问答记录 ID 75-78 保留，历史读取接口不再返回方法不存在错误。
- 英文回答主体已使用英文，但模型仍可能直接引用中文原记录，不能宣称英文翻译完全一致。
- 153 项后端 unittest、19 项前端 Node 测试通过；前端生产构建通过；页面无 JS 异常。
- 本轮时延不是五秒内完成的保证。全视频上下文更长，耗时还受本地模型并发影响。

## 尚未解决的回答准确性问题

额外询问全视频装袋记录时，模型正确引用了 `10:30-10:35`，但又误引了相邻的
`10:35-10:40`。数据库中后者仅描述器械接触、起雾；另一个装袋摘要实际在
`10:45-10:48.567`。因此本次确认的是**跨片段上下文访问与回放链接功能已修复**，
不代表本地模型的事件识别或所有时间引用已达到可靠性要求。

原始输出保留在该会话的问答历史及中文补测截图中。没有用固定视频时间规则修改这个答案，
也没有将未通过样本隐藏成成功结果。
