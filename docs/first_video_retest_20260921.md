## 实际发现与修正

### 历史循环回放停止了后台时间推进

主视频进入历史循环后，原先只在主视频 timeupdate 时发送播放位置，导致数据库时间
停在进入循环前，分析窗口不再增加。现在历史回看使用独立的直播时钟发送心跳，
退出后继续当前直播位置。暂停、跳转、返回首页和组件卸载清理独立时钟。

实际在软件中回看窗口 1 约 25 秒：后台位置从 352.13 增长到 379.48 秒，
分析窗口从 69 增加到 75；退出 5 秒后位置 384.53 秒，窗口 76。
截图：`loop_enter.png`、`loop_exit.png`。首轮录屏包含这次操作。

后台没有新窗口的等待超时也从循环计数改为实际单调时间；有新采集帧时不会错误超时。

### 不确定的组织被强制补成胆囊管

旧视觉结果归一化会把 unknown 替换为 Triplet 倾向，缺少提示时默认为胆囊管，
并抬高置信度。现在保留 unknown，不把专家先验伪装成图像证据。
普通血管、胆囊蒂也不能自动等同于胆囊动脉、胆囊管。
真实夹子可保留，但目标不清楚时不强行指定具体组织。

### 否定词清理反转了描述含义

旧规则可能只删除“未见”，留下“剪刀”“施夹”等肯定字样。现在删除完整的
否定检查条目，不删除单独的否定词。增加了真实肯定观察仍保留的测试。

### 本地模型复制空的 JSON 示例

旧长提示词给出了完整的全 false 示例，多个窗口实际返回空摘要及默认值。
本地分支改用紧凑的图像事实提示词和字段类型定义，不再提供可直接复制的默认答案。
外部模型的原提示词保留。单次本地调用仍联合判断器械、夹子、剪切、纱布、出血、CVS、视野。
正常无出血不等于“出血已控制”，始终清晰不等于“雾已去除”。

视觉后更新替换本地专家初稿，初稿仍存于 metadata，不再把新旧冲突的句子简单拼接。

### 阶段一次误判造成后续永久锁定

第一轮窗口 90 的夹闭切断投票仅 4/12，随后短暂预测胆囊分离、清洁凝血，
不可回退规则将后续分析锁定在清洁凝血，连真实夹子复核也被阶段过滤。

修复后，新阶段需连续三个窗口的足够置信度与多数帧投票，再提交阶段转换。
器械及动作仍每 5 秒更新；形态复核确认的真实施夹可立即进入夹闭阶段。
阶段不再阻止本地视觉分支检查真实夹子，当前复核确认的夹子事实也不能被阶段文案删除。
这不是对所有术式或所有阶段关系的临床验证；单一阶段模型仍可能误判。

### 模糊和屏幕图标被当成体外场景

体外复核提示词排除角落标志、字幕、边框和 UI 图标。仅红色满屏、灰白模糊、
过曝不能证明镜头移出体外。需明确场景证据及两个不同抽帧中的证据位置。
测试的 375、390、395 秒窗口不再仅凭模糊判为体外，返回视野受遮挡。
这里无法仅凭模糊画面判断镜头物理位置，保留不确定性比补猜安全。

### 五分钟前的历史图片被清理

模拟器被按无限实时流执行 300 秒滚动保留，早期事件图片和回放帧会消失。
有限本地模拟视频现在保留整段采样帧，真实无限采集流的原保留预算不变。
被旧版本清掉的帧不会因代码修复自动恢复；新完整会话重新采集。

- 右侧历史合并不再把阶段标题当作唯一摘要；保留具体动作。去掉界面层把管状结构

### 尚未通过的准确性与体验项

1. Phase 专家后半段仍可能过早判断清洁凝血；连续三个窗口确认只能减少跳变，不能修复持续的模型误分类。
2. 胆囊管、胆囊动脉的特异性判断未经过医生标注验证，不能将置信度数字当成准确率。
3. 完整运行中的留置夹体与施夹器动作仍有混淆。例如窗口 193 原片主要显示已留置夹子，复核却输出了施夹动作。
   追加提示词抽查已改善这个样本，但尚未重新跑全片验证，也不能据此统计夹子数量。
4. 模糊、遮挡与真实起雾尚未可靠区分，现有起雾节点文案有时比图像证据更肯定。
5. “雾已去除”节点的封面有时仍取到窗口前部的模糊帧；封面不是该状态已正确识别的证明。
6. 最新窗口初稿仍可能短暂误判，视觉后更新也未达到 5 秒以内。

下一步应使用更多独立视频继续检验器械形态、静态夹体和动态动作的区分，
并把具体动作证据与阶段先验分开；不应通过写死窗口号、颜色或视频时间来补答案。
