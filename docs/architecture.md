## 3. 服务端口分配

| 服务 | 端口 | 说明 |
|------|------|------|
| Frontend (Vue.js) | 5176 | 前端开发服务器 |
| Backend (FastAPI) | 8001 | 后端API服务 |
| GLM-4.6V-Flash | 8000 | 多模态大语言模型 (vLLM) |
| SurgR1 | 9003 | 手术图像分析模型 (vLLM) |
| SAM3 | 9004 | 图像分割模型 |
| TTS CosyVoice | 50000 | 语音合成服务 |
| ASR FunASR | 8765 | 语音识别服务 |
| RTC Simulator HTTP | 9001 | 视频流模拟器 |
| RTC Simulator WebRTC | 9002 | WebRTC信令服务 |
| MySQL | 3306 | 数据库服务 |

## 5. 技术栈

### 前端
- Vue.js 3 (Composition API)
- Vite 构建工具
- Axios HTTP客户端
- WebSocket 实时通信

### 后端
- FastAPI 异步Web框架
- SQLAlchemy ORM
- httpx 异步HTTP客户端
- websockets 实时通信

### AI模型
- vLLM 高效推理引擎
- GLM-4.6V-Flash 多模态大语言模型
- SurgR1 手术图像分析模型
- SAM3 图像分割模型
- FunASR 语音识别模型
- CosyVoice 语音合成模型

### 数据存储
- MySQL 分析结果持久化
- SQLite 会话管理

### 通信协议
- HTTP/HTTPS REST API
- WebSocket 实时双向通信
- WebRTC 视频流传输
